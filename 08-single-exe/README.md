# 三角洲分辨率切换 v1.0.0

单个原生 Windows 程序，包含设置界面、托盘监测、显示模式切换和恢复；不需要 PowerShell 或额外的脚本文件。适用于 Windows 桌面，实际可用模式由显卡驱动和显示器决定。

## 使用

1. 如安装了旧版，请先在旧版设置中关闭登录自启、退出旧版托盘程序，并确认屏幕已恢复原分辨率。
2. 将 `DeltaResolution.exe` 放到固定位置并双击。第一次启动会打开设置窗口。
3. 选择 Steam、官方启动器或 WeGame，选择自动同高度 4:3 或填写自定义分辨率，点击“检查分辨率”。检查不会实际切换。
4. 如需开机自动启动，勾选“登录 Windows 后自动启动”；点击“保存设置”。关闭窗口后，后台和托盘图标继续运行。
5. 双击托盘图标或右键选择“打开设置”。重复启动同一个程序也会打开设置窗口。右键托盘选择“退出监测”会结束后台；若当前处于已切换状态，退出时会尝试恢复。

Steam 和官方模式会尝试检测启动器；WeGame 模式在游戏主进程出现后触发。退出游戏后恢复切换前的主显示器分辨率、色深和刷新率。如果程序意外退出，在下次启动时可点击“恢复原分辨率”；也可以通过 Windows 显示设置手动调整。显示器或驱动模式发生变化时，恢复可能失败。

配置、恢复记录和 `error.log` 保存在 `%LOCALAPPDATA%\DeltaResolution`；可从设置界面打开日志。登录自启使用当前用户启动文件夹快捷方式，取消勾选并保存即可移除。通常不需要管理员权限，不更改注册表或游戏文件。

## 测试和已知限制

已用模拟显示接口验证两轮启动/退出的切换与恢复顺序；在同一台电脑隔离空闲运行的 20 秒样本中，测试副本工作集约 11.3 MiB，私有内存约 2.52 MiB，采样 CPU 时间小于计时精度。实际占用因电脑和运行时状态而异。

**尚未完成真实游戏、各平台启动器、显示驱动及实际切换的端到端实机测试。** WeGame 可能在游戏开始运行后才切换；平台更新可能改变进程名。程序只识别进程名，不核对路径。切换可能暂时黑屏或改变窗口布局。

## 构建

使用包含 Windows 头文件的 MinGW GCC：

```
gcc -O2 -Wall -Wextra -Werror -mwindows -o DeltaResolution.exe DeltaResolution.c -lshell32 -luser32 -lgdi32 -lole32 -luuid
```
