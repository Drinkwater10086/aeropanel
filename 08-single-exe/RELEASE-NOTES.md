# v1.0.0 — 单文件原生版

- 设置界面、托盘监测、分辨率检查、切换与恢复均集成在一个原生 EXE 中；不依赖 PowerShell 脚本。
- 支持 Steam、官方启动器、WeGame 进程检测，同高度 4:3 或自定义分辨率。
- 支持当前用户登录自启、异常后手动恢复和详细错误日志。
- 20 秒隔离空闲样本：工作集约 11.3 MiB、私有内存约 2.52 MiB；CPU 时间在采样精度内未检出。结果不可视为所有电脑或游戏期间的保证。

测试范围：已模拟两轮游戏启动与退出；真实游戏与真实显示切换尚未完成端到端实机验证。WeGame 可能在游戏进程出现后切换。安装旧版的用户请先停止并关闭旧版自启。
