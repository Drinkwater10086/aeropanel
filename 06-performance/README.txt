三角洲分辨率设置

1. 解压到一个长期保留、当前用户可写的文件夹，不要在压缩包内运行。
2. 双击 Open-Settings.bat。选择 Steam、官方启动器或 WeGame，选择自动同高度 4:3 或填写分辨率。
3. 点击“检查分辨率”，验证驱动是否接受该模式；然后点击“启用登录自启”。也可仅点击“启动后台”运行本次。
4. 设置窗口可关闭。后台右下角托盘图标可以打开设置或退出监测；图标是否折叠在 ^ 菜单中由 Windows 决定。
5. 在设置界面可关闭自启、停止后台、恢复原分辨率和查看 error.log。关闭自启不会停止当前后台；停止后台不会关闭自启。

切换前保存主显示器原显示模式，游戏退出后恢复。目标分辨率必须由显示驱动支持；模式检查不会实际切换。WeGame 只在游戏进程出现后触发，Steam / 官方模式会尝试检测启动器。各平台进程名称可能随版本变化。
窗口关闭不会终止后台。设置改变在下次切换时生效。后台使用约两秒一次的进程检查和系统托盘消息循环。显示切换代码在首次需要切换时加载；长时间运行或切换后的资源占用尚未测量。
如果旧版正在运行，请先用旧版卸载脚本关闭自启并停止后台，等待退出后再启用本版。不要同时运行多个版本。
异常终止后如未自动恢复，先停止后台，再通过设置窗口恢复；如没有可恢复记录，请在 Windows 显示设置中手动恢复。
