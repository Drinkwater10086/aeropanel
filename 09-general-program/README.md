# 分辨率自动切换：通用程序版

单文件原生 Windows 程序：设置界面、后台监测、托盘和分辨率切换均在一个 EXE 内。一次启用一个监听目标，可以选择“三角洲预设”或“指定其他程序”。

## 使用

1. 更新前，在旧版设置里关闭登录自启并保存，然后通过旧版托盘菜单退出后台，确认原分辨率已恢复。
2. 将 `ResolutionSwitcher.exe` 放到长期保留的位置并打开。程序会在 Windows 通知区域显示托盘图标；关闭设置窗口后后台继续运行。
3. 通用程序：选择“指定其他程序”，点击“浏览…”并选择实际运行的 EXE（不是快捷方式），再选择自动同高度 4:3 或填写目标分辨率。
4. 三角洲：选择对应的 Steam、官方启动器或 WeGame 预设。Steam 和官方模式尝试在对应启动器出现时提前切换；WeGame 模式等待游戏主进程出现。
5. 点击“检查分辨率”验证显示驱动是否接受目标模式，再点击“保存设置”。如需每次登录自动启动，勾选相应选项后保存。
6. 通用程序模式下，在当前用户 Windows 会话中找到指定路径的进程时切换；所有匹配该路径的进程退出后恢复切换前的显示模式。修改设置会在当前目标退出、恢复后生效。

如果应用先打开启动器然后启动不同的实际游戏进程，通用模式只会监听你选中的那个 EXE。要匹配游戏本体，请选择游戏的实际运行文件。程序会比较可执行文件的完整路径，不会把不同目录下的同名程序当成同一个目标。路径长度限制为 259 字符以内；路径别名、符号链接和文件重定位后的路径可能需要重新选择。

由于权限限制，如果无法确认同名进程的路径，程序不会猜测进程是否为目标，而会暂时保持当前显示模式并写入错误日志。异常结束后重新启动，可点击“恢复原分辨率”；没有有效恢复记录时可通过 Windows 显示设置手动恢复。设置、恢复数据和错误日志保存在 `%LOCALAPPDATA%\DeltaResolution`，关闭登录自启需取消勾选并保存。

## 已验证和限制

隔离测试使用模拟显示接口，没有修改真实屏幕分辨率。已测试中文路径的保存读取、不同目录下同名程序的识别、访问被拒绝时避免提前恢复、运行中变更目标、退出恢复，以及三角洲三个预设的模拟触发流程。

真实程序中的实际分辨率切换与恢复尚未完成端到端实机测试。除 Steam 外，其他三角洲渠道均未实机测试；本版本的 Steam 完整流程也尚未实机验证。进程名可能因游戏或平台更新而变化。显示模式必须由显示驱动和显示器支持，切换可能短暂黑屏。

隔离空闲测试中，通用模式测试副本在 20 秒测量窗口结束时工作集约 11.33 MiB、私有内存约 1.80 MiB，单核心口径平均 CPU 约 0.078%。这只是一次短时采样，不代表所有机器或游戏期间的占用。

## 构建

```text
gcc -O2 -s -Wall -Wextra -Werror -mwindows -o ResolutionSwitcher.exe ResolutionSwitcher.c -lshell32 -luser32 -lgdi32 -lole32 -luuid -lcomdlg32
```
