# v2.0.0 — 通用程序监听与三角洲预设

## 本次变化

- 新增“指定其他程序”：选择实际运行的 EXE，按完整路径监听；程序启动后切换到指定分辨率，所有匹配实例退出后恢复原显示模式。
- 保留三角洲 Steam、官方启动器和 WeGame 三种特殊预设。Steam 和官方模式尝试提前检测启动器，WeGame 等待游戏主进程出现。
- 支持中文路径和同名程序隔离；当前显示模式已切换时，更改监听目标会在本次目标退出并恢复后生效。
- 无法读取同名进程路径时保持当前显示模式并记录错误，避免错误地提前恢复。
- 继续使用单个原生 EXE，保留托盘、自动同高度 4:3、自定义宽高、登录自启和异常后的手动恢复。一次启用一个监听目标。

## 升级与使用

先在旧版设置中关闭登录自启并保存，再从旧版托盘退出后台。双击 `ResolutionSwitcher.exe`，选择“指定其他程序”或三角洲预设，检查分辨率后保存。需要登录自启时重新勾选并保存；普通模式请选择实际运行的 EXE，而非快捷方式。

配置和恢复数据仍使用 `%LOCALAPPDATA%\DeltaResolution`，兼容 v1 的三角洲渠道和分辨率配置。启动后请确认设置，程序路径需短于 260 字符。通用模式只匹配当前 Windows 会话中的指定路径进程。

## 测试范围与性能

已用真实测试进程和模拟显示接口验证：中文路径、同名程序隔离、权限不足保护、运行中更改目标、退出恢复，以及三个三角洲预设的模拟触发流程。

**除 Steam 外，其他三角洲渠道均未实机测试；本版本 Steam 完整流程和普通程序实际分辨率切换，也尚未完成端到端实机验证。** 支持的显示模式以显卡驱动和显示器为准，切换可能暂时黑屏。

一次 20 秒隔离空闲采样中，通用模式测试副本工作集约 11.33 MiB、私有内存约 1.80 MiB，单核心口径平均 CPU 约 0.078%。这是短时样本，不代表所有机器或游戏期间的占用。
