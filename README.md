# 三角洲行动自动切换分辨率

Windows PowerShell 脚本的四个现存版本，按开发顺序保存。版本目录为原始归档的快照，并非补造的 Git 提交历史；部分中间修改曾覆盖同名归档，未在此保存。

1. `01-manual`：手动启动脚本，固定切换 2880×2160，退出后恢复 3840×2160。
2. `02-auto-fixed`：后台检测启动器和游戏，使用固定分辨率。
3. `03-auto-4x3`：根据主显示器高度计算 4:3 分辨率，保存并恢复原显示模式。
4. `04-multi-platform`：在自动 4:3 版本上增加其他启动器进程检测。

## 当前版本使用方法

将 `04-multi-platform` 文件夹放在长期保留的可写位置，双击 `Check-Modes.bat` 检查显示模式，再运行 `Install-AutoStart.bat`。它会为当前用户创建开机启动快捷方式并启动后台监测。卸载时运行 `Uninstall-AutoStart.bat`；如需恢复已保存的显示模式，运行 `Restore-Original.bat`。

后台每约两秒检查一次进程。切换目标保持当前主显示器高度，宽度为高度的 4/3；显示模式必须由显卡驱动支持。游戏结束后恢复切换前保存的模式。仅在语法及保存/读取方面做过检查，尚未完成实际分辨率切换和各平台游戏流程的实机测试。WeGame 模式可能要等游戏主进程出现后才触发，具体版本的进程名也可能变化。

历史版本仅供参考，部分版本将恢复分辨率固定为 3840×2160。切换可能暂时黑屏；强制结束后台程序后可能需要使用恢复脚本或 Windows 显示设置手动恢复。
