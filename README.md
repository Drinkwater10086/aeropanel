# 三角洲行动自动切换分辨率

Windows PowerShell 脚本，按开发顺序保留七个版本。前四个版本来自当时保存的归档，部分被覆盖的中间版本无法还原。

1. `01-manual`：手动启动，固定切换 2880×2160 并恢复 3840×2160。
2. `02-auto-fixed`：后台检测，使用固定分辨率。
3. `03-auto-4x3`：按主显示器高度计算 4:3，保存并恢复原模式。
4. `04-multi-platform`：增加多平台进程检测。
5. `05-tray-settings`：新增设置界面、托盘菜单、自定义分辨率和错误日志；[改动与性能试测](05-tray-settings/CHANGELOG.md)。
6. `06-performance`：优化空闲轮询和显示代码加载；[性能对比](06-performance/PERFORMANCE.md)。
7. `07-native`：原生托盘监测后台；[使用与性能试测](07-native/README.md)。

## 使用最新版本

将 `07-native` 文件夹放在长期保留、当前用户可写的位置，双击 `Open-Settings.bat`。选择平台和分辨率后，点击“检查分辨率”，再点击“启动后台”或“启用登录自启”。设置窗口关闭后，可通过通知区域图标重新打开设置或退出后台。

先卸载并停止旧版本，避免同时运行。关闭登录自启和停止当前后台是两个独立操作。异常退出后可先停止后台，再在设置界面选择“恢复原分辨率”。

驱动必须支持选定的显示模式；WeGame 可能要等游戏主进程出现后才触发。目标和刷新率取决于显示设备。已检查脚本语法和设置窗口创建，实际托盘操作、切换及各平台启动流程尚未完成实机测试。历史版本中有固定恢复为 3840×2160 的逻辑。
