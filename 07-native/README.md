# 三角洲分辨率自动切换：原生后台版

## 使用

解压到当前用户可写且长期保留的文件夹，双击 `Open-Settings.bat`。选择平台和目标分辨率，点击“检查分辨率”，再选择“启动后台”或“启用登录自启”。关闭设置窗口后可从通知区域托盘图标重新打开设置或停止后台。关闭登录自启和停止当前后台是独立操作。

更新前请先在旧版界面关闭自启并停止后台，等待旧版退出，再启用本版。异常退出后如未恢复，先停止后台，再点击“恢复原分辨率”；若无保存记录，请在 Windows 显示设置中手动恢复。

## 设计与限制

常驻的 `DeltaWatcher.exe` 使用原生 Windows 接口和两秒定时器，不常驻 PowerShell。打开设置和进行分辨率切换/恢复时，会临时运行系统 PowerShell；因此切换时的瞬时资源消耗高于空闲后台。程序不修改注册表、驱动或游戏文件；可选的自启通过当前用户启动文件夹快捷方式实现。

WeGame 在游戏进程出现后触发；Steam 和官方启动器尝试在识别到对应启动器时触发。进程名或游戏启动流程可能因平台更新而变化。支持的分辨率和刷新率以驱动为准。更改设置在下次切换时应用。

错误写入 `error.log`，设置界面可打开。运行依赖 Windows 图形桌面和系统 Windows PowerShell。尚未实机验证完整的托盘交互及真实游戏中的显示切换。

## 性能试测

同一台电脑，隔离运行 `06-performance` 和本版，替换游戏进程名，避免真实切换。预热 8 秒后观察 20 秒；设置窗口关闭，内存为结束时进程读数。

| 指标 | 旧版 PowerShell 后台 | 原生后台 |
|---|---:|---:|
| 平均 CPU（单逻辑核心为 100%） | 0.391% | 0.078% |
| 工作集 | 112.18 MiB | 9.85 MiB |
| 私有内存 | 76.81 MiB | 2.33 MiB |

短时空闲测试中的 CPU 数据精度有限；不同机器、游戏中和切换时结果可能不同。原生后台通过虚拟启动器和游戏信号测试了切换及恢复顺序，测试中的切换操作为模拟实现，并未更改真实显示设置。

源代码 `Watcher.c` 与可执行程序一同提供。可用带 Windows 头文件的 MinGW GCC 编译：`gcc -O2 -Wall -Wextra -mwindows -o DeltaWatcher.exe Watcher.c -lshell32 -luser32`。
