# AeroPanel v3.0.0

- 原项目更名为 AeroPanel，支持通用程序，保留三角洲渠道预设与仓库历史。
- 硬件监控与分辨率切换整合为两个板块，共用原生窗口、托盘和主进程。
- 透明监控、左上角默认位置、字号 26、数值与图表显示。
- 设置窗口可缩放、最大化和全屏，字体随窗口缩放。
- FPS 无需 RTSS，使用内嵌 PresentMon 2.3.1 采集；硬件监控仍依赖 MSI Afterburner。
- 帧统计改用部分选择并复用缓冲，批量解析 CSV，降低关闭模块时的轮询开销。
- 驱动检查、15 秒分辨率试用、退出恢复和持久恢复记录。
- 重新编译后 62 项回归通过。性能及实屏切换的既有样本与限制见 TESTING.md。

发行包不含个人配置、日志、安装路径或真实进程标识。无有效帧事件时仍会显示 N/A；不保证覆盖独占全屏或系统安全桌面。
