# AeroPanel v3.0.8

- 新增自动硬件数据源。MSI Afterburner 可用时使用其共享读数，并由小型 AOT 助手采集主板 CPU 电压。共享数据不可用时启用完整 AOT 硬件采集。
- CPU 电压显示支持已实测的技嘉 B650M AORUS ELITE AX ICE 主板通道 IT8689E Voltage #1。
- 开启增强 API 识别时，管理员助手可合并图形事件采集和硬件转发。降低后台轮询，缓存传感器选择，并延缓短暂的数据源切换。
- 支持 Ctrl + Alt + F10 切换置顶浮窗。隐藏时暂停帧率和帧时间采集。
- 更新前台应用分辨率规则及三角洲规则的处理。

本机共通过 106 项回归测试。硬件验证覆盖本机 14 项读数及浮窗隐藏、显示流程。AOT 依赖仍有兼容性警告。其他硬件和游戏内性能未全面验证。Video FPS 扩展仍为 v1.1.3。
