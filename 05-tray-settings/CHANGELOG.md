# 托盘和设置界面版本

相较于 `04-multi-platform`：

- 新增按需打开的设置窗口，可选择 Steam、官方启动器或 WeGame，选择同高度 4:3 或输入自定义宽高。
- 后台增加通知区域图标与菜单，设置窗口关闭后无需常驻；Windows 决定图标是否放入折叠菜单。
- 提供分辨率检查、后台启动和停止、登录自启开关、原模式恢复和错误日志入口。失败日志包含阶段、异常详情和脚本路径。
- 后台仍约每两秒检查一次进程。WeGame 仅在游戏主进程出现后触发；其他平台尝试检测对应启动器。

## 空闲性能试测

在一台 Windows 电脑上，用隔离副本启动旧版 `04-multi-platform` 和新版后台，将游戏及启动器进程名替换为不存在的测试名称，防止改变屏幕分辨率。启动预热 8 秒后，在同一 20 秒时间窗口内测量进程的 CPU 时间、结束时工作集及私有内存；设置窗口未打开。两者均为 Windows PowerShell 后台进程。没有进行游戏运行时测试。

| 指标 | 旧版 | 托盘版 | 差值 |
|---|---:|---:|---:|
| 平均 CPU（以单个逻辑核心为 100%） | 0.234% | 0.156% | -0.078 个百分点 |
| 工作集 | 97.1 MiB | 119.9 MiB | +22.8 MiB |
| 私有内存 | 72.4 MiB | 85.0 MiB | +12.6 MiB |

这只是一次短时空闲采样，CPU 数值很小，调度和计时精度会显著影响差值，不能据此认定新版 CPU 更省。内存为采样终点的进程读数，并非峰值；不同机器、运行时间及系统负载会导致不同结果。设置窗口打开时、游戏运行时和长时间运行的消耗尚未测量。

脚本语法及设置窗口创建已检查；实际托盘操作、分辨率切换和三种平台启动流程仍需实机验证。
